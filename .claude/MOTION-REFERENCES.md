# Références Motion Design

> Sources d'inspiration officielles pour **tout travail de motion design** (vidéos promo, explainers, animations, cartes offre, intros de marque…).
> Auteur : Enock Mahougnan · Dernière mise à jour : 2026-10-16

## 📌 Consigne (pour Claude)

**Avant de produire une animation ou une vidéo motion design, s'inspirer des références ci-dessous** — pour le rythme, les transitions, la qualité et le niveau de finition. Objectif : des rendus **professionnels, dynamiques et propres**, jamais plats ni génériques.

- S'inspirer du **style, du timing et de la structure** de ces animations — **sans copier** une pièce à l'identique (adapter à la marque / au projet).
- Combiner avec les skills motion déjà installés (`brand-launch-video-star`, HyperFrames, Remotion, le pack `vibe-motion`, `disney-animation-rule-skill`).
- Pour chaque pièce de référence : regarder le film **puis** lire le prompt associé pour comprendre quelle formulation produit quel mouvement (easing, morphing, pacing, caméra).

## 🎬 Référence principale

### promptmotion.org — https://promptmotion.org/
Galerie d'environ **230 films de motion design réalisés avec Claude**, chacun accompagné du **prompt (ou du skill) qui l'a produit**, avec lien vers le post d'origine du créateur. Inclut une **bibliothèque de 1000+ prompts** (brief = scène · typo · timing · caméra).

**Ce qu'on y trouve (catégories utiles) :**
- **Showreels** : motion designer showreel, kinetic type, geometric motion.
- **Promos / lancements produit** : promo showreel, launch video, app promo. → utile pour les pubs Emk Blue Diamond / IA Business Building.
- **UI motion** : morphing UI states, badge unlock, transitions d'écrans.
- **Explainers** : concepts expliqués (ex. « What is Git »), stop-motion.
- **Pièces stylisées / génératives** : pixel art, risograph, oscilloscope, 3D beat-synced, scènes cinématiques.

**Stacks repérés dans les pièces** : three.js, Blender, Remotion, Manim, HTML/SVG, CSS (vérifier le détail sur chaque entrée).

**Comment m'en servir :**
1. Filtrer par catégorie pour trouver un style proche de la cible (ex. « product promo », « kinetic type »).
2. Étudier la structure du prompt (scène / typo / timing / caméra) comme checklist de brief.
3. Comparer prompt → rendu pour réutiliser la bonne formulation.
4. Adapter à la marque, créditer le créateur si on réutilise une approche.
